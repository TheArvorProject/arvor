**Arvor Linux is an atomic, mutable Linux distribution based on Debian made by The Arvor Project**

## Tools

### nsm 

nsm (NextFerret Snapshot Manager) It is the tool responsible for LVM Thin snapshots,made in C and with integration with weld.

### Weld

Weld is the package manager for Arvor Linux, written in C++26 and dependent on Libapt (the library behind apt and apt-get).

### NFLXS

NFLXS (NextFerret Linux Sandboxes) is a container manager that uses the Docker API, without relying on insecure kernel modules like OverlayFS. 


## Minimum Requirements 

### x86_64 (AMD64)

CPU: Any processor with 2 cores (not tested with 1 core)
RAM: 2 GB ((Not tested with less RAM)
GPU: any.
